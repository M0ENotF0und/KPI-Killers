1. On github.com click New repository, name it (e.g. ereteti-sacco), leave it empty, Create.
2. In a terminal inside this folder:

   git init
   git add .
   git commit -m "Restyle Ereteti Dairy Sacco site"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/ereteti-sacco.git
   git push -u origin main

3. Optional live site: repo Settings > Pages > Deploy from branch > main / (root).
