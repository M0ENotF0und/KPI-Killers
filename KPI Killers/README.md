# Ereteti Dairy Sacco

A multi-page website for Ereteti Dairy Sacco (Ngong), built with HTML and CSS.
Restyled with a terracotta and cream theme, Fraunces headings and Nunito Sans body text.

**Live site:** https://YOUR-USERNAME.github.io/YOUR-REPO/

## Pages
- `index.html` – home
- `about.html` – history of the sacco
- `routes.html` – collection routes and times
- `contact.html` – address, phone, email
- `register.html` – membership application form
- `deliveries.html` – daily milk delivery table

## Structure
- `css/style.css` – all styling (colours and fonts are CSS variables at the top)
- `img/` – logo, favicon and photos
- `practice/` – practice drills
